No special artifacts needed. Dependencies are already installed in `node_modules/`. Copy `.env` from the main checkout if missing.

## How to run the server

Port 3000 is occupied by another service. Use port 4000:

```bash
cd C:/Users/ADMIN/Downloads/ebook-site
PORT=4000 node server.js
```

Server listens on port 4000 in this worktree.
